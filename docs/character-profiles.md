- 재질: PP 소재
- 투명도: 고투명

### 보관함
- 캐릭터 카드 전용 케이스
- 칸막이 4개 (캐릭터별 분리)
- 마그네틱 잠금

---

## 사용 방법

### 게임 시작 시
1. 각 플레이어가 캐릭터 카드 1장 선택
2. 앞면을 확인하여 난이도 파악
3. 뒷면 정보로 전략 수립
4. 캐릭터별 시작 점수에 말 배치

### 게임 중
- 캐릭터 카드는 항상 앞면으로 놓기
- 특성을 참고하여 플레이
- 전용 카드는 조건 충족 시 사용

### 참고 사항
- 뒷면 정보는 언제든지 확인 가능
- 다른 플레이어 카드도 열람 가능 (정보 공개)

---

## 디지털 버전

### 앱/웹 버전 시
- 3D 카드 뒤집기 애니메이션
- 터치로 상세 정보 확인
- 캐릭터별 음성 지원
- 일러스트 애니메이션

---
