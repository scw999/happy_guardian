# 특수 이벤트 칸 가이드

## 이벤트 칸 시스템

특수 이벤트 칸에 도착하면 **상황 카드**를 뽑고, 주어진 선택지 중 하나를 선택해야 합니다. 선택에 따라 점수가 크게 변동되므로 신중하게 결정해야 합니다.

### 이벤트 카드 구조
- **상황 설명**: 현재 발생한 상황
- **선택지**: 3-4가지 선택 가능한 행동/대답
- **결과**: 각 선택지별 점수 변화 및 추가 효과

---

## 대화 상황 이벤트 (30장)

### 📱 메시지 관련 이벤트

#### 이벤트 #1: 늦은 답장
**상황**: "왜 이제야 답장해? (읽씹 2시간)"

**선택지**:
1. "미안, 회의 중이었어" → **+5점** (평범한 변명)
2. "늦어서 정말 미안해. 회의 끝나자마자 바로 연락했어" → **+12점** (진심 있는 사과)
3. "나도 바쁘거든?" → **-25점** (최악의 선택)
4. *기적의 논리 카드 사용 가능* → 선택지 무시하고 안전하게 +10점

**특수 효과**:
- 선택지 3 선택 시 다음 턴까지 모든 대화 카드 점수 -5점

---

#### 이벤트 #2: 단답 메시지
**상황**: "오늘 뭐해?" / "응" / "ㅇㅋ" 같은 단답만 보냄

**선택지**:
1. "왜 그래? 무슨 일 있어?" → **+15점** (관심 표현)
2. 똑같이 단답으로 대응 → **-10점** (관심 없음)
3. "피곤해? 푹 쉬어~" → **+8점** (배려)
4. 무시하고 다른 얘기 → **-15점** (둔감)

**특수 효과**:
- 선택지 1 선택 시 다음 칸에서 대화 카드 효과 +5점

---

#### 이벤트 #3: 밤 늦은 전화 요청
**상황**: "지금 통화 가능해?" (새벽 1시)

**선택지**:
1. "물론이지, 무슨 일이야?" → **+20점** (최고의 선택)
2. "졸려... 내일 얘기하자" → **-15점** (냉정함)
3. "10분만 통화하자" → **+10점** (타협안)
4. 전화 받지 않음 → **-30점** (최악)

**특수 효과**:
- 선택지 1 선택 시: 친밀도 보너스로 다음 3턴 동안 모든 대화 액션 +3점
- 선택지 4 선택 시: 2턴 동안 "신뢰도 하락" 상태 (모든 점수 획득 -50%)

---

### 💬 일상 대화 이벤트

#### 이벤트 #4: "나 살쪘어?"
**상황**: 여자친구가 거울을 보며 묻습니다.

**선택지**:
1. "아니야, 전혀 안 쪘어" → **+8점** (무난)
2. "조금? 그래도 귀여워" → **-20점** (최악)
3. "원래도 예뻤고 지금도 예뻐" → **+15점** (완벽한 답)
4. "운동 같이 할까?" → **-18점** (암묵적 인정)

**캐릭터별 특수 반응**:
- 완벽주의 센서티브: 선택지 2, 4 선택 시 **-30점** (2배 페널티)
- 비타민 긍정녀: 선택지 2 선택해도 **-10점**만 감소

---

#### 이벤트 #5: "우리 얼마나 좋아해?"
**상황**: 갑자기 사랑의 크기를 물어봅니다.

**선택지**:
1. "많이 좋아하지" → **+5점** (성의 없음)
2. "세상에서 제일 좋아해" → **+12점** (직접적 표현)
3. "말로 표현 못 할 만큼" → **+10점** (감성적)
4. *구체적 사례 제시*: "어제 네가 웃을 때 행복했어. 매일 너 생각해" → **+18점** (최고)

**특수 효과**:
- 선택지 4 선택 시: "깊은 교감" 토큰 획득 → 다음 위기 상황 1회 자동 회피

---

#### 이벤트 #6: "전 여자친구랑 비교하면?"
**상황**: 위험한 질문이 날아왔습니다!

**선택지**:
1. "너가 훨씬 나아" → **-15점** (비교 자체가 문제)
2. "비교할 수 없지, 너는 특별해" → **+15점** (좋은 답변)
3. "왜 갑자기 그런 얘기를 해?" → **-5점** (회피)
4. "전 여친은 과거야, 지금은 너만 생각해" → **+20점** (완벽한 답)

**특수 효과**:
- 선택지 1 선택 시: 즉시 "과거 회상 카드" 추가로 1장 뽑기
- 선택지 4 선택 시: "신뢰도 상승" → 2턴 동안 모든 페널티 -5점 감소

---

### 🤔 의견 충돌 이벤트

#### 이벤트 #7: 영화 취향 차이
**상황**: "나는 로맨스 보고 싶은데 너는 액션 보자고 해"

**선택지**:
1. "그럼 로맨스 보자" → **+15점** (양보)
2. "액션이 더 재밌어" → **-20점** (고집)
3. "로맨스 보고 다음엔 액션 보자" → **+20점** (타협)
4. "네가 좋으면 나도 좋아" → **+10점** (무난)

**특수 효과**:
- 선택지 3 선택 시: "완벽한 타협" 토큰 → 다음 의견 충돌 이벤트에서 +10점 보너스

---

#### 이벤트 #8: 친구 모임 vs 데이트
**상황**: "오늘 친구들이랑 약속 있는데... 너도 보고 싶어"

**선택지**:
1. "친구들 만나, 나는 괜찮아" → **+18점** (배려)
2. "나랑 있어줘" → **-12점** (이기적)
3. "친구들이랑 놀다가 저녁에 보자" → **+22점** (최고의 타협)
4. "친구가 더 중요하구나" → **-25점** (삐침)

**특수 효과**:
- 선택지 1, 3 선택 시: "성숙한 연인" 상태 → 2턴 동안 모든 액션 +5점
- 선택지 4 선택 시: 즉시 분노 모드 진입

---

### 😤 감정 폭발 이벤트

#### 이벤트 #9: 이유 없는 짜증
**상황**: "그냥 다 싫어" (이유를 말하지 않음)

**선택지**:
1. "왜 그래? 무슨 일 있어?" → **+12점** (관심)
2. "나한테 왜 화풀이해?" → **-30점** (최악)
3. 조용히 안아주기 → **+20점** (완벽한 대응)
4. "시간 줄까? 진정하고 얘기하자" → **+15점** (성숙한 대응)

**캐릭터별 특수 반응**:
- 완벽주의 센서티브: 선택지 3 효과 **+30점**
- 논리적인 커리어우먼: 선택지 4 효과 **+22점**

**특수 효과**:
- 선택지 2 선택 시: 관계 위기 → 점수가 현재의 70%로 감소

---

#### 이벤트 #10: "너는 내 마음도 몰라!"
**상황**: 갑자기 감정이 폭발했습니다.

**선택지**:
1. "그럼 말을 해줘야지" → **-15점** (책임 전가)
2. "미안해, 내가 둔감했어. 뭐가 문제였어?" → **+20점** (진심 어린 사과)
3. "나도 답답해" → **-25점** (감정 대응)
4. "내가 잘못했어. 천천히 얘기해줄래?" → **+25점** (최고의 대응)

**특수 효과**:
- 선택지 4 선택 시: "깊은 이해" 토큰 → 향후 모든 "과거 회상" 카드 면역

---

### 💔 관계 위기 이벤트

#### 이벤트 #11: "우리 관계 어떻게 생각해?"
**상황**: 진지한 관계 점검 대화

**선택지**:
1. "잘 되고 있는 것 같은데?" → **+5점** (성의 없음)
2. "가끔 힘들긴 하지만 너랑 있으면 행복해" → **+18점** (솔직함)
3. "너는 어떻게 생각해?" → **-10점** (회피)
4. "부족한 점 있으면 말해줘. 고칠게" → **+22점** (성장 의지)

**특수 효과**:
- 선택지 4 선택 시: "성장하는 관계" 영구 토큰 → 이후 모든 실수 페널티 -3점 감소

---

#### 이벤트 #12: "잠깐 시간 가질까?"
**상황**: 헤어지자는 뜻일 수도 있는 위험한 제안

**선택지**:
1. "그래, 그러자" → **-40점** (포기)
2. "왜? 무슨 문제 있어? 얘기하자" → **+15점** (적극적 해결)
3. "시간 가지면 해결돼? 지금 얘기하자" → **+25점** (즉각 대응)
4. "내가 뭘 잘못했어?" → **-5점** (방어적)

**특수 효과**:
- 선택지 1 선택 시: 게임 오버 위기 → 즉시 특수 카드 사용 기회 부여
- 선택지 3 선택 시: 위기 극복 시 +30점 추가 보너스

## 돌발 질문 이벤트 (20장)

### 🎯 기억력 테스트

#### 이벤트 #13: "우리 처음 만난 날 기억나?"
**상황**: 갑작스런 기억력 테스트

**선택지**:
1. "음... 언제더라?" → **-20점** (최악)
2. 정확한 날짜 기억 → **+25점** (완벽)
3. "그때 네가 입었던 옷 기억나" (구체적 디테일) → **+30점** (감동)
4. "기억 안 나지만 그날부터 행복했어" → **+10점** (감성 회피)

**난이도 체크**: 주사위 굴리기
- 6: 자동으로 정확히 기억 (+25점)
- 4-5: 대략적으로 기억 (+15점)
- 1-3: 기억 못함 (-20점)

---

#### 이벤트 #14: "내가 제일 좋아하는 음식 뭐게?"
**상황**: 취향 파악 확인

**선택지**:
1. 정확히 맞춤 → **+20점**
2. 비슷한 종류 맞춤 → **+10점**
3. 완전히 틀림 → **-15점**
4. "많아서 기억이... 다시 알려줘?" → **-8점** (솔직한 고백)

**캐릭터별 특수 반응**:
- 완벽주의 센서티브: 틀리면 **-25점**
- 비타민 긍정녀: 틀려도 **-8점**만

---

#### 이벤트 #15: "내 생일 언제게?"
**상황**: 절대 틀리면 안 되는 질문

**선택지**:
1. 정확히 맞춤 → **+15점**
2. 월은 맞췄는데 일이 틀림 → **-25점**
3. 완전히 틀림 → **-50점** + 즉시 기념일 잊음 페널티
4. *기적의 논리 카드로 회피 가능*

**특수 효과**:
- 틀릴 경우: 다음 3턴 동안 "신뢰도 추락" 상태

---

### 🔮 미래 계획 질문

#### 이벤트 #16: "우리 1년 후엔 뭐 하고 있을까?"
**상황**: 미래에 대한 생각 확인

**선택지**:
1. "글쎄... 모르지" → **-15점** (무관심)
2. "지금처럼 행복하게 있겠지" → **+12점** (무난)
3. "같이 여행도 가고, 더 깊이 알아가고 있을 거야" → **+20점** (구체적 상상)
4. "결혼 생각해봤어" → **+30점** 또는 **-20점** (관계 단계에 따라 다름)

**캐릭터별 특수 반응**:
- 논리적인 커리어우먼: 선택지 3 효과 **+25점** (구체적 계획 선호)
- 반전 매력의 츤데레: 선택지 4를 60점 이상일 때 선택하면 **+40점**

#### 이벤트 #17: "부모님께 소개시켜줄 거야?"
**상황**: 진지한 관계 의지 확인

**선택지**:
1. "아직은..." → **-18점** (회피)
2. "물론이지, 언제든 괜찮아" → **+25점** (적극적)
3. "준비되면 당연히 소개시켜줄게" → **+15점** (신중)
4. "너는 소개시켜줄 거야?" → **-10점** (질문으로 회피)

**특수 효과**:
- 선택지 2 선택 시: "진심 확인" 토큰 → 향후 모든 관계 위기 이벤트 +10점 보너스

### 😱 함정 질문

## 돌발 상황 이벤트 (25장)

### 😡 위기 상황

#### 이벤트 #21: 예쁜 여자가 말 걸어옴
**상황**: 길 가다가 다른 여자가 당신에게 말을 겁니다. 여자친구가 옆에 있습니다.

**선택지**:
1. 친절하게 대응 → **-20점**
2. 무시하고 여자친구 손 잡기 → **+25점** (최고의 선택)
3. 짧게 대답하고 끝내기 → **+10점** (무난)
4. 번호 물어보면 어쩔 수 없이 줌 → **-60점** (게임 오버 위기)

**특수 효과**:
- 선택지 2 선택 시: "확실한 애정 표현" 토큰 → 다음 2턴 동안 모든 액션 +8점

---

#### 이벤트 #22: 전 여자친구 우연히 마주침
**상황**: 길에서 전 여자친구를 마주쳤습니다.

**선택지**:
1. 반갑게 인사 → **-25점**
2. 간단히 인사하고 빨리 자리 떠남 → **+10점**
3. 못 본 척 → **+15점** (현재 여친 우선)
4. "내 여자친구야" 소개 → **+20점** (확실한 관계 표시)

---

#### 이벤트 #23: 휴대폰을 보고 싶어함
**상황**: "휴대폰 좀 봐도 돼?"

**선택지**:
1. "왜?" (방어적) → **-15점**
2. "응, 봐" (자연스럽게 건네기) → **+20점** (신뢰 표시)
3. "나도 네 거 봐도 돼?" → **-10점** (의심 유발)
4. "숨길 거 없어" (건네며 설명) → **+25점** (완벽한 신뢰)

**특수 효과**:
- 선택지 2, 4 선택 시: "완전한 신뢰" 영구 토큰 → 향후 의심 관련 이벤트 자동 +15점

---

### 🎉 호감 상승 기회

#### 이벤트 #24: 아파서 누워있음
**상황**: 여자친구가 감기에 걸렸습니다.

**선택지**:
1. "푹 쉬어" (문자만) → **+5점**
2. 약이랑 죽 사들고 방문 → **+30점** (최고)
3. 전화로 위로 → **+12점**
4. 다 나을 때까지 기다림 → **-10점** (무관심)

**특수 효과**:
- 선택지 2 선택 시: "헌신적 사랑" 토큰 → 영구적으로 모든 위기 이벤트 +10점 보너스

---

#### 이벤트 #25: 회사/학교에서 힘든 일
**상황**: "오늘 상사한테/교수님한테 혼났어..."

**선택지**:
1. "너도 잘못한 거 있겠지" → **-30점** (최악)
2. "힘들었겠다. 괜찮아?" → **+15점** (공감)
3. "어떻게 된 거야?" (자세히 들어주기) → **+20점** (적극적 경청)
4. 직접 만나서 위로 → **+28점** (행동으로 보여주기)

**캐릭터별 특수 반응**:
- 논리적인 커리어우먼: 선택지 3 효과 **+30점** (경청 중시)

---

#### 이벤트 #26: SNS에 다른 여자와 사진
**상황**: 당신의 SNS에 다른 여자가 태그된 사진이 올라왔습니다.

**선택지**:
1. 설명 없이 방치 → **-35점**
2. "회사 동료야" (간단 설명) → **+5점**
3. 먼저 "이거 회사 팀 회식이야" 설명 문자 → **+18점** (선제 대응)
4. 사진 바로 삭제하고 설명 → **+25점** (배려)

**특수 효과**:
- 선택지 1 선택 시: "신뢰도 붕괴" → 3턴 동안 모든 대화/공감 카드 효과 없음

### 💝 프러포즈 급 이벤트

**특수 효과**:
