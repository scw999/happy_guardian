# 보드판 디자인

## 보드판 개요

해피 하트 가디언의 보드판은 **원형(순환형)** 디자인으로, 총 **40칸**으로 구성됩니다.

### 보드판 사양

- **형태**: 원형 순환 트랙
- **총 칸 수**: 40칸
- **권장 보드 크기**: 60cm × 60cm
- **칸 크기**: 약 4cm × 4cm
- **중앙 영역**: 카드 더미 배치 공간

## 특수 칸 설명

### 시작 칸 (칸 1)
- **이름**: "새로운 시작"
- **효과**: 시작점이자 일반 데이트 칸
- **특별 규칙**: 한 바퀴 돌아 다시 시작점 통과 시 +10점 보너스

### 중간 쉼터 (칸 20)
- **이름**: "숨 고르기"
- **효과**: 휴식 칸 (+5점 자동)
- **특별 규칙**: 이곳에 도착하면 손패 1장 추가 드로우 가능

### 중앙 영역
- **용도**: 카드 더미 배치
- **배치 항목**:
  - 액션 카드 더미
  - 특수 카드 더미
  - 돌발 변수 카드 더미
  - 특수 이벤트 카드 3개 덱 (쉬움/보통/어려움)
  - 버린 카드 더미
  - 점수 트랙 (0-100)

## 제작 사양

### 권장 재질

**보드판**:
- 두께: 2mm 하드보드 또는 접이식 보드
- 표면: 코팅 처리 (내구성)
- 접기: 4단 접기 (60cm → 15cm)

**칸 표시**:
- 인쇄 방식: 오프셋 인쇄 또는 디지털 인쇄
- 마감: 무광 또는 반광 코팅
- 내구성: 방수 코팅

**점수 트랙**:
- 별도 점수판 또는 보드 가장자리에 통합
- 0-100까지 5점 단위 눈금
