# 캐릭터 상세 가이드

## 캐릭터 개요

해피 하트 가디언에는 4가지 고유한 캐릭터가 있으며, 각각 다른 플레이 스타일과 전략을 요구합니다.

---

## 1. 완벽주의 센서티브

### 기본 정보
- **난이도**: ⭐⭐⭐⭐⭐ (최상)
- **시작 점수**: 30점
- **추천 플레이어**: 고급 플레이어
- **플레이 스타일**: 하이리스크 하이리턴

### 상세 특성

#### 능력치
```
기본 기분: ★☆☆☆☆ (매우 낮음)
변동성:   ★★★★★ (매우 높음)
보상:     ★★★★★ (매우 높음)
난이도:   ★★★★★ (최상)
```

#### 고유 능력
- **완벽주의자**: 취향 저격 액션 시 점수 2배 (예: +15점 → +30점)
- **예민함**: 모든 페널티 2배 (예: -10점 → -20점)
- **높은 기준**: 보통 수준의 액션은 점수 변화 없음

#### 취향 카드
완벽주의 센서티브가 선호하는 액션:

1. **세심한 준비**
   - 효과: +20점 → +40점 (2배 적용)
   - 예시: 미리 예약한 레스토랑, 기념일 준비

2. **맞춤형 선물**
   - 효과: +15점 → +30점
   - 예시: 평소 원하던 정확한 아이템

3. **깊이 있는 대화**
   - 효과: +12점 → +24점
   - 예시: 진지한 감정 공유

#### 주의사항 (페널티 2배)
- ❌ 작은 약속 어김: -10점 → -20점
- ❌ 부주의한 말: -8점 → -16점
- ❌ 디테일 놓침: -12점 → -24점

### 승리 전략

#### 초반 전략 (30-50점)
1. **취향 파악 최우선**: 액션 카드를 신중하게 선택
2. **안전 카드 확보**: 기적의 논리 카드, 공감 마스터 카드 비축
3. **리스크 회피**: 불확실한 액션 자제

#### 중반 전략 (50-75점)
1. **공격적 플레이**: 취향 저격 카드로 대량 점수 획득
2. **연계 보너스**: 연속 성공으로 추가 점수
3. **이벤트 칸 피하기**: 돌발 변수 최소화

#### 후반 전략 (75-100점)
1. **확실한 카드만 사용**: 실수로 탈락 방지
2. **방어적 플레이**: 현재 점수 유지에 집중
3. **인내 카드 활용**: 위험 구간 방어

## 2. 비타민 긍정녀

### 기본 정보
- **난이도**: ⭐⭐ (하)
- **시작 점수**: 70점
- **추천 플레이어**: 초보자
- **플레이 스타일**: 안정적 관리

### 상세 특성

#### 능력치
```
기본 기분: ★★★★☆ (높음)
변동성:   ★★☆☆☆ (낮음)
보상:     ★★★☆☆ (보통)
난이도:   ★★☆☆☆ (쉬움)
```

#### 고유 능력
- **긍정적 성격**: 모든 페널티 -50% 감소 (예: -10점 → -5점)
- **외로움 수치**: 방치 시 매 턴 -3점 자동 감소
- **쉬운 만족**: 기본 액션만으로도 충분한 점수 획득

#### 취향 카드
비타민 긍정녀가 선호하는 액션:

1. **일상적 관심**
   - 효과: +8점
   - 예시: 간단한 문자, 전화

2. **함께하는 시간**
   - 효과: +10점
   - 예시: 산책, 영화, 맛집

3. **작은 선물**
   - 효과: +7점
   - 예시: 커피, 간식, 꽃

#### 특별 메커니즘: 외로움 수치
```
턴 경과 시 액션 없음 → 외로움 수치 +1
외로움 수치 누적:
- 1턴 방치: -3점
- 2턴 연속 방치: -6점 (-3 × 2)
- 3턴 연속 방치: -9점 (-3 × 3)

리셋 조건: 어떤 액션이든 수행 시 외로움 수치 0으로 초기화
```

### 승리 전략

#### 핵심 원칙
- **꾸준함이 핵심**: 매 턴 작은 액션이라도 수행
- **방치 금지**: 외로움 수치 누적 방지
- **안정적 점수 관리**: 큰 점수보다 꾸준한 소득

#### 빠른 승리법 (10-12턴 승리)
1. 매 턴 데이트/대화 칸 선택
2. 연속 액션 보너스 활용
3. 70점 → 100점까지 안정적으로 상승

## 3. 반전 매력의 츤데레

### 기본 정보
- **난이도**: ⭐⭐⭐ (중)
- **시작 점수**: 50점
- **추천 플레이어**: 중급 플레이어
- **플레이 스타일**: 계획적 플레이

### 상세 특성

#### 능력치
```
기본 기분: ★★★☆☆ (보통)
변동성:   ★★★☆☆ (보통)
보상:     ★★★★☆ (높음)
난이도:   ★★★☆☆ (중간)
```

#### 고유 능력
- **지연 반응**: 모든 액션 효과가 다음 턴에 적용
- **안정성**: 점수가 오르면 자연 감소 없음
- **예측 어려움**: 현재 기분 상태 비공개

#### 특별 메커니즘: 지연 반응

```
현재 턴 (3턴): 데이트 카드 사용 (+10점 예정)
현재 점수: 50점 (변화 없음)

다음 턴 (4턴): 이전 액션 효과 적용
최종 점수: 60점 (+10점 적용)
```

**전략적 의미**:
- 2-3턴 앞을 내다보는 계획 필요
- 실시간 점수 파악 불가
- 연계 액션 계획 가능

### 승리 전략

#### 초반 전략 (1-5턴)
1. **공격적 투자**: 높은 점수 액션 연속 수행
2. **효과 예측**: 2턴 후 점수 계산
3. **기록 유지**: 사용한 카드 메모

#### 중반 전략 (6-10턴)
1. **연계 효과**: 턴마다 높은 점수 액션
2. **안정 구간 진입**: 60-70점대 유지
3. **방어 카드 준비**: 돌발 상황 대비

#### 후반 전략 (11-15턴)
1. **최종 스퍼트**: 마지막 3턴에 집중 투자
2. **계산된 승리**: 정확한 턴 계산으로 100점 도달

## 4. 논리적인 커리어우먼

### 기본 정보
- **난이도**: ⭐⭐⭐⭐ (상)
- **시작 점수**: 50점
- **추천 플레이어**: 고급 플레이어
- **플레이 스타일**: 전략적 대화

### 상세 특성

#### 능력치
```
기본 기분: ★★★☆☆ (보통)
변동성:   ★★★★☆ (높음)
보상:     ★★★★☆ (높음)
난이도:   ★★★★☆ (어려움)
```

#### 고유 능력
- **대화 선호**: 대화/공감 카드 효과 +50%
- **선물 무관심**: 선물 카드 효과 -30%
- **말실수 민감**: 잘못된 대화 선택 시 페널티 +50%

#### 점수 계산 예시

| 액션 유형 | 기본 점수 | 적용 후 점수 |
|----------|----------|-------------|
| 완벽한 대화 | +12점 | +18점 (+50%) |
| 공감 표현 | +10점 | +15점 (+50%) |
| 선물 | +15점 | +10점 (-30%) |
| 말실수 | -10점 | -15점 (+50% 페널티) |

### 승리 전략

#### 핵심 원칙
1. **대화 칸 최우선**: 이동 경로를 대화 칸 중심으로
2. **선물 회피**: 선물 칸은 효율이 낮음
3. **신중한 선택**: 대화 선택지 신중하게 고려

#### 카드 우선순위
1. 🥇 공감 마스터 카드 (대화 칸에서 +22점)
2. 🥈 깊이 있는 대화 카드 (+18점)
3. 🥉 커리어 응원 카드 (+20점, 고유 카드)

#### 주의사항
- ❌ 영혼 없는 공감: -10점 → -15점
- ❌ "원래 그런 거야" 류의 답변: -12점 → -18점
- ❌ 조언 강요: -8점 → -12점

## 캐릭터 선택 가이드

### 첫 플레이 추천 순서
1. **1차 플레이**: 비타민 긍정녀 (게임 이해)
2. **2차 플레이**: 반전 매력의 츤데레 (전략 연습)
3. **3차 플레이**: 논리적인 커리어우먼 (심화 학습)
4. **4차 플레이**: 완벽주의 센서티브 (마스터 도전)

### 플레이어 성향별 추천

#### 안정적 플레이 선호
→ **비타민 긍정녀**
- 낮은 리스크
- 예측 가능한 게임 흐름
- 초보자 친화적

#### 전략적 플레이 선호
→ **반전 매력의 츤데레** 또는 **논리적인 커리어우먼**
- 계획성 요구
- 높은 보상
- 선택의 중요성

#### 도전적 플레이 선호
→ **완벽주의 센서티브**
- 최고 난이도
- 극한의 긴장감
- 숙련자용
