# 아이콘 가이드

## 개요

해피 하트 가디언에서 사용되는 모든 아이콘의 의미, 디자인 사양, 사용 규칙을 정의합니다.

---

## 보드판 칸 아이콘

### 💑 데이트 칸
**의미**: 연인과 함께하는 시간
**색상**: #FF69B4 (핫핑크)
**디자인 요소**:
- 두 사람의 실루엣 또는 하트 두 개
- 따뜻하고 로맨틱한 느낌
- 부드러운 곡선 강조

**사용 위치**:
- 보드판: 12칸
- 액션 카드: 데이트 카드 20장

**변형**:
- 🎬 영화 데이트 (영화 필름 + 하트)
- 🍽️ 맛집 데이트 (포크+나이프 + 하트)
- 🚶 산책 데이트 (발자국 + 하트)

---

### 🎁 선물 칸
**의미**: 선물을 주고받는 행위
**색상**: #FFD700 (골드)
**디자인 요소**:
- 리본이 달린 선물 상자
- 반짝임 효과
- 기대감을 주는 디자인

**사용 위치**:
- 보드판: 8칸
- 액션 카드: 선물 카드 15장

**변형**:
- 💐 꽃 선물 (꽃다발)
- 💄 화장품 (립스틱)
- 📚 책 선물 (열린 책)
- 👜 패션 아이템 (핸드백)

---

### 💬 대화 칸
**의미**: 소통과 대화
**색상**: #87CEEB (스카이블루)
**디자인 요소**:
- 말풍선 모양
- 깨끗하고 명료한 라인
- 소통을 상징하는 화살표 가능

**사용 위치**:
- 보드판: 8칸
- 액션 카드: 대화 카드 20장

**변형**:
- 💬 일상 대화 (기본 말풍선)
- 🎯 깊이 있는 대화 (말풍선 + 하트)
- 💝 사랑 고백 (하트 말풍선)
- 🤝 공감 표현 (겹쳐진 말풍선)

---

### 🎭 특수 이벤트 칸
**의미**: 예상치 못한 상황과 선택
**색상**: #9370DB (미디엄퍼플)
**디자인 요소**:

**사용 위치**:
- 보드판: 8칸
- 특수 이벤트 카드: 75장

**하위 카테고리**:
- 💬 대화 상황 (말풍선 + 가면)
- ❓ 돌발 질문 (물음표 + 가면)
- ⚠️ 위기 상황 (경고 + 가면)

## 점수 변화 아이콘

### ⬆️ 점수 상승
**사용**: +점수 표시
**색상**: #32CD32 (라임그린)
**크기**: 점수에 비례
- +1~10점: 작은 화살표
- +11~20점: 중간 화살표
- +21점 이상: 큰 화살표

### ⬇️ 점수 하락
**사용**: -점수 표시
**색상**: #DC143C (크림슨)
**크기**: 페널티에 비례
- -1~10점: 작은 화살표
- -11~20점: 중간 화살표
- -21점 이상: 큰 화살표

### ✖️ 2배 효과
**사용**: 주기 모드, 특수 효과
**색상**: #9370DB
**표시**: "×2" 텍스트

## 아이콘 디자인 원칙

### 1. 일관성
- 모든 아이콘은 동일한 스타일 유지
- 라인 두께 일정 (2-3px)
- 모서리 라운딩 통일

### 2. 가독성
- 최소 크기 16×16px에서도 식별 가능
- 명확한 실루엣
- 충분한 여백

### 3. 색상 접근성
- 색맹 사용자 고려
- 충분한 명도 대비 (최소 4.5:1)
- 색상 외 다른 구분 요소 병행

### 4. 확장성
- 벡터 기반 제작 (SVG)
- 다양한 크기 대응
- 해상도 독립적

### 5. 직관성
- 보편적 상징 사용
- 문화적 배경 고려
- 학습 곡선 최소화

## 아이콘 파일 형식

### 제작용
- **Adobe Illustrator** (.ai)
- **SVG** (웹/앱용)
- **PDF** (인쇄용)

### 사용용
- **PNG** (72dpi, 96dpi, 144dpi)
- **SVG** (벡터, 확장 가능)
- **Icon Font** (웹 최적화)

### 크기 변형
- 16×16px (작은 UI)
- 24×24px (일반 UI)
- 32×32px (카드)
- 64×64px (보드판)
- 128×128px (대형 표시)
