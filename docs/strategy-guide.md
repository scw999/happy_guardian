## 기본 전략

### 승리의 3원칙

#### 1. 점수 관리
- **목표 설정**: 매 5턴마다 +20점씩 상승 목표
- **안전 마진**: 항상 20점 이상 여유 유지
- **위험 구간**: 30점 이하는 탈락 위험

#### 2. 카드 효율
- **고점수 카드 우선**: 15점 이상 카드를 전략적으로 사용
- **콤보 구성**: 연계 가능한 카드 세트 유지
- **특수 카드 타이밍**: 결정적 순간을 위해 보존

#### 3. 리스크 관리
- **이벤트 칸 회피**: 가능하면 안전한 경로 선택
- **방어 카드 확보**: 최소 1장 이상 보유
- **주기 카드 대비**: 인내 카드 준비

```
전략: 확실한 카드만 사용
- 공감 마스터 카드 (보장 15점)
```

### 논리적인 커리어우먼 대화 마스터

#### 대화 중심 전략
```
기본 방침:
- 대화/공감 카드만 사용 (+50% 보너스)
- 선물 카드는 최후의 수단 (-30% 페널티)

점수 효율 비교:
선물 카드 (15점): 15 × 0.7 = 10.5점
대화 카드 (12점): 12 × 1.5 = 18점
→ 대화가 1.7배 효율적!
```

#### 이동 경로 최적화
```
보드판에서 대화 칸 위치 파악
├─ 대화 칸: 3, 7, 11, 15, 19, 23
├─ 선물 칸: 5, 10, 16, 21 (회피!)
└─ 데이트 칸: 2, 6, 12, 18, 24

주사위 결과별 대응:
현재 위치 1:
- 주사위 2 → 대화 칸 (3) ✅
- 주사위 4 → 선물 칸 (5) ❌
→ 주사위 2 나오길 기도하거나 이동 조작 카드 사용
```

#### 말실수 절대 금지 목록
```
❌ 피해야 할 대화 선택지:
1. "원래 그런 거야" (-18점)
2. "예민하게 굴지 마" (-20점)
3. "내 친구 여자친구는..." (-25점)
4. "너무 깊게 생각하는 거 아니야?" (-15점)

✅ 안전한 대화 선택지:
1. "네 기분 충분히 이해해" (+18점)
2. "내가 생각이 짧았어" (+15점)
3. "너의 의견을 듣고 싶어" (+18점)
```

#### 커리어우먼 최적 카드 덱
```
필수 카드 (7장 구성):
1. 공감 마스터 × 2 (22점 보장)
2. 깊이 있는 대화 × 2 (18점 × 2)
3. 커리어 응원 × 1 (20점, 전용 카드)
4. 공감 표현 × 1 (15점)
5. 기적의 논리 × 1 (방어용)
```

## 보드 동선 최적화

### 보드판 구조 이해
```
칸 배치 (총 24칸, 순환 구조):
시작 - 1 - 2(데이트) - 3(대화) - 4 - 5(선물) - 6(데이트) -
7(대화) - 8(이벤트) - 9 - 10(선물) - 11(대화) - 12(데이트) -
13 - 14(휴식) - 15(대화) - 16(선물) - 17 - 18(데이트) -
19(대화) - 20(이벤트) - 21(선물) - 22 - 23(대화) - 24(데이트)
```

### 고효율 경로

#### 대화 루트 (논리적인 커리어우먼 추천)
```
목표: 대화 칸 최대한 방문
경로: 3 → 7 → 11 → 15 → 19 → 23
필요 주사위: 4, 4, 4, 4, 4 (평균)
예상 점수: 18 × 6 = 108점 (승리!)
```

#### 데이트 루트 (비타민 긍정녀 추천)
```
목표: 데이트 칸으로 안정적 점수
경로: 2 → 6 → 12 → 18 → 24
필요 주사위: 4, 4, 6, 6, 6
예상 점수: 12 × 5 = 60점 (보조 수단)
```

#### 이벤트 회피 루트 (완벽주의 센서티브 추천)
```
위험 칸: 8, 20 (이벤트 칸)
안전 경로: 7 → 9 → 19 → 21
→ 이벤트 칸 피하고 안전하게 점수 획득
```

### 주사위 확률 계산
```
6면 주사위 확률:
- 특정 숫자 (예: 6): 16.7%
- 범위 (예: 4-6): 50%
- 범위 (예: 1-3): 50%

기대값: 3.5

전략적 위치 선정:
목표 칸이 7이고 현재 위치가 3일 때:
- 주사위 4 필요: 16.7% (낮음)
→ 다른 칸도 좋은 위치 선택
```

## 카드 관리

### 카드 드로우 최적화

#### 드로우 타이밍
```
기본 드로우: 매 턴 종료 시 1장
추가 드로우: 특정 칸 도착 시

최대 효율 전략:
1. 카드 수 5-6장 유지 (여유 공간)
2. 불필요한 카드 버리기
3. 필요한 카드 수집
```

#### 카드 버리기 우선순위
```
버려야 할 카드:
1. 캐릭터와 안 맞는 카드
   - 선물 카드 (논리적인 커리어우먼)
   - 복잡한 카드 (비타민 긍정녀)

2. 중복 카드
   - 같은 효과 카드 3장 이상

3. 타이밍 지난 카드
   - 초반용 카드를 후반에 보유
```

### 손패 구성

#### 이상적인 7장 덱
```
균형잡힌 구성:
1. 고점수 카드 × 2 (15점+)
2. 안정 카드 × 3 (8-12점)
3. 방어 카드 × 1 (기적의 논리, 인내)
4. 상황 대응 카드 × 1 (공감 마스터 등)
```

#### 캐릭터별 최적 덱

**완벽주의 센서티브:**
```
1. 취향 저격 선물 (25점 → 50점)
2. 패션 아이템 (15점 → 30점)
3. 깊이 있는 대화 (12점 → 24점)
4. 공감 마스터 (15점 → 30점)
5. 기적의 논리 (방어)
6. 타임 프리즈 (방어)
7. 사랑 고백 (15점 → 30점)
```

**비타민 긍정녀:**
```
1. 문자/전화 (외로움 리셋)
2. 산책 데이트 (보너스 +2)
3. 일상 대화 (안정)
4. 영화 데이트 (안정)
5. 꽃 선물 (중간)
6. 행복 충전 (전용, 외로움 제거)
7. 아무 카드 (여유)
```

## 위기 대응

### 주요 위기 상황과 대응

#### 위기 1: 주기 카드 발동 (변동성 모드)
```
상황: 3턴 동안 점수 변화 2배
위험도: ★★★★★

대응 전략:
옵션 A) 공격적 대응
- 고점수 카드 사용 (+25점 → +50점)
- 리스크: 실수 시 -40점 이상

옵션 B) 방어적 대응
- 인내 카드 사용 (3턴 버티기)
- 안전하지만 점수 획득 없음

옵션 C) 혼합 전략 (추천)
- 1턴: 인내 카드 (보호)
- 2턴: 확실한 카드 (+20점 → +40점)
- 3턴: 인내 카드 (보호)
→ 안전하게 40점 획득
```

#### 위기 2: 점수 30점 이하 (탈락 위험)
```
상황: 한 번의 실수면 게임 오버
위험도: ★★★★★

즉시 행동:
1. 방어 카드 모두 사용 (타임 프리즈 등)
2. 100% 확실한 카드만 사용
3. 이벤트 칸 절대 회피
4. 작은 점수라도 꾸준히 획득

회복 계획:
30점 → 40점 (안전 카드 +10)
40점 → 55점 (확실한 카드 +15)
55점 → 70점 (안정 구간)
```

#### 위기 3: 과거 회상 카드
```
상황: "그때 왜 그랬어?" 질문
위험도: ★★★★☆

대응:
1. 기억력 테스트
   - 게임 초반 발생 이벤트 기억
   - 사용했던 카드 기록 확인

2. 불확실하면
   - 솔직하게 "잘 기억 안 나" (-35점)
   - 거짓말로 더 큰 피해 (-50점+) 방지

3. 예방책
   - 중요 이벤트 메모
   - 카드 사용 기록
```

#### 위기 4: 카드 부족
```
상황: 손패에 쓸 만한 카드 없음
위험도: ★★★☆☆

해결책:
1. 특정 칸 방문으로 드로우 증가
2. 현재 카드로 최선의 플레이
3. 다음 턴 드로우 기대
4. 방어적 플레이로 버티기
```

### 분노 상태 복구 전략

#### 분노 레벨별 대응
```
레벨 1: -10점 ~ -20점 (경미)
대응: 공감 표현 카드 (+10점, 페널티 감소)
회복: 2-3턴

레벨 2: -20점 ~ -40점 (중간)
대응: 기적의 논리 카드 (절반 회복)
      + 공감 마스터 카드
회복: 3-4턴

레벨 3: -40점 이상 (심각)
대응: 모든 방어 카드 총동원
      1. 기적의 논리 (-40 → -20)
      2. 타임 프리즈 (다음 턴 보호)
      3. 공감 마스터 (+15)
      4. 깊이 있는 대화 (+12)
회복: 5턴 이상
```

## 고급 테크닉

### 확률 계산

#### 기대값 기반 의사결정
```
선택지 A: 확실한 +10점
선택지 B: 50% 확률로 +25점, 50% 확률로 -10점

기대값 계산:
A: 10점 (100%)
B: (25 × 0.5) + (-10 × 0.5) = 7.5점

→ 점수만 보면 A 선택
→ 하지만 역전 필요시 B 선택 가능
```

### 심리전

#### 카드 사용 타이밍
```
상대가 관찰하는 요소:
1. 언제 방어 카드를 쓰는가?
2. 공격적인가 방어적인가?
3. 어떤 칸을 선호하는가?

블러핑:
- 약한 카드를 망설이며 사용 (강한 척)
- 강한 카드를 빠르게 사용 (약한 척)
```

## 숙련도별 목표

### 초보자 (1-5판)
```
목표:
- 게임 오버 안 되기
- 한 캐릭터 완전히 이해하기
- 기본 카드 효과 암기

권장 캐릭터: 비타민 긍정녀
```

### 중급자 (6-15판)
```
목표:
- 100점 승리 1회 이상
- 3가지 캐릭터 플레이
- 카드 콤보 구사

권장 캐릭터: 츤데레, 커리어우먼
```

### 고급자 (16판 이상)
```
목표:
- 모든 캐릭터 마스터
- 10턴 이내 승리
- 완벽주의 센서티브 승리

최종 도전: 완벽주의 센서티브로 8턴 승리
```

## 마무리: 승리를 위한 10계명

1. **캐릭터 특성을 파악하라** - 각 캐릭터의 강점 활용
2. **카드 효율을 계산하라** - 점수/리스크 비율 고려
3. **방어 카드를 확보하라** - 최소 1장 이상 보유
4. **주기 카드를 대비하라** - 인내 카드 준비
5. **이벤트 칸을 피하라** - 불필요한 리스크 회피
6. **연계 콤보를 구사하라** - 카드 시너지 활용
7. **점수 여유를 유지하라** - 20점 이상 안전 마진
8. **말실수를 조심하라** - 특히 커리어우먼 상대
9. **타이밍을 노려라** - 특수 카드는 결정적 순간에
10. **끝까지 집중하라** - 마지막까지 방심 금물
