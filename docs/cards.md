# 카드 목록

## 카드 체계 개요

해피 하트 가디언의 카드는 크게 3가지 범주로 나뉩니다:

1. **액션 카드**: 플레이어가 직접 사용하는 카드 (60장)
2. **돌발 변수 카드**: 이벤트 칸에서 뽑는 카드 (30장)
3. **특수 카드**: 제한적으로 사용 가능한 강력한 카드 (10장)

---

## 1. 액션 카드 (총 60장)

### 데이트 카드 (20장)

#### 🎬 영화 데이트
- **점수**: +10점
- **특수 효과**: 로맨스 영화 선택 시 추가 +2점
- **수량**: 5장
- **설명**: 영화관에서 함께 영화를 봅니다.

#### 🍽️ 맛집 데이트
- **점수**: +10점
- **특수 효과**: 처음 가는 곳이면 추가 +3점
- **수량**: 5장
- **설명**: 새로운 레스토랑을 함께 방문합니다.

#### 🚶 산책 데이트
- **점수**: +8점
- **특수 효과**: 비타민 긍정녀에게 +2점 추가
- **수량**: 4장
- **설명**: 공원이나 강변을 함께 걷습니다.

#### 🎨 문화 생활 데이트
- **점수**: +12점
- **특수 효과**: 논리적인 커리어우먼에게 +3점 추가
- **수량**: 3장
- **설명**: 전시회, 공연, 박물관 관람.

#### 🏠 홈 데이트
- **점수**: +9점
- **특수 효과**: 츄데레에게 +4점 추가 (다음 턴)
- **수량**: 3장
- **설명**: 집에서 함께 요리하거나 영화를 봅니다.

---

### 선물 카드 (15장)

#### 💐 꽃 선물
- **점수**: +8점
- **특수 효과**: 기념일에 사용 시 +5점
- **수량**: 4장
- **설명**: 계절의 꽃다발을 선물합니다.

#### 💄 화장품/향수
- **점수**: +12점
- **특수 효과**: 취향 일치 시 +8점 추가
- **수량**: 3장
- **설명**: 평소 관심 있던 뷰티 제품.

#### 📚 책/잡지
- **점수**: +10점
- **특수 효과**: 논리적인 커리어우먼에게 +5점 추가
- **수량**: 2장
- **설명**: 관심 분야의 책을 선물합니다.

#### 👜 패션 아이템
- **점수**: +15점
- **특수 효과**: 완벽주의 센서티브에게 2배 (30점)
- **수량**: 3장
- **설명**: 옷, 가방, 액세서리 등.

#### 🎁 깜짝 선물
- **점수**: +10점
- **특수 효과**: 주사위 5-6 시 +10점 추가
- **수량**: 3장
- **설명**: 예상치 못한 선물로 놀라게 합니다.

---

### 대화 카드 (20장)

#### 💬 일상 대화
- **점수**: +7점
- **특수 효과**: 연속 3턴 사용 시 +3점 보너스
- **수량**: 6장
- **설명**: "오늘 어땠어?" 같은 일상적 대화.

#### 🎯 깊이 있는 대화
- **점수**: +12점
- **특수 효과**: 논리적인 커리어우먼에게 +6점 추가
- **수량**: 4장
- **설명**: 진지한 감정, 미래, 가치관 공유.

#### 💝 사랑 고백
- **점수**: +15점
- **특수 효과**: 70점 이상일 때 +5점 추가
- **수량**: 3장
- **설명**: "사랑해" 진심 어린 고백.

#### 🤝 공감 표현
- **점수**: +10점
- **특수 효과**: 분노 상태일 때 페널티 -5점 감소
- **수량**: 4장
- **설명**: "힘들었겠다", "네 마음 이해해" 등.

#### 😊 칭찬
- **점수**: +8점
- **특수 효과**: 구체적일수록 효과 증가
- **수량**: 3장
- **설명**: 외모, 능력, 성격 등을 칭찬.

---

### 관심 표현 카드 (5장)

#### 📱 문자/전화
- **점수**: +5점
- **특수 효과**: 비타민 긍정녀의 외로움 수치 리셋
- **수량**: 3장
- **설명**: 간단한 안부 문자나 전화.

#### 📸 SNS 커플 인증
- **점수**: +6점
- **특수 효과**: 특정 돌발 변수 예방
- **수량**: 2장
- **설명**: 함께 찍은 사진을 SNS에 올립니다.

## 2. 특수 카드 (총 10장)

### 방어 카드

#### 🌟 기적의 논리 카드
- **사용 조건**: 분노 상태 (마이너스 점수) 일 때
- **효과**: "내가 다 잘못했어" - 마이너스 점수의 절반 회복
- **예시**: -40점 → -20점
- **수량**: 2장

#### 🛡️ 인내 카드
- **사용 조건**: 주기(변동성 모드) 중
- **효과**: 한 턴 동안 점수 변화 없음 (보호)
- **수량**: 3장

#### 🔮 타임 프리즈
- **사용 조건**: 언제든지
- **효과**: 다음 턴까지 모든 페널티 무효화
- **수량**: 2장

### 공격 카드

#### 🎉 서프라이즈 이벤트 카드
- **사용 조건**: 언제든지
- **효과**: 주사위 4-6 성공 시 +50점 / 1-3 실패 시 -15점
- **수량**: 2장

#### 💝 공감 마스터 카드
- **사용 조건**: 대화 칸에서
- **효과**: 어떤 선택지든 최고 점수 보장 (+15점)
- **수량**: 2장

#### 🎯 취향 저격 선물 카드
- **사용 조건**: 선물 칸에서
- **효과**: 100% 취향 일치 (+25점)
- **수량**: 2장

## 3. 돌발 변수 카드 (총 30장)

### 긍정적 카드 (10장)

#### 🌈 예상치 못한 칭찬
- **효과**: 즉시 +15점
- **발생**: "오늘 진짜 멋있어 보인다"
- **수량**: 4장

#### 🎊 친구들의 칭찬
- **효과**: 즉시 +10점
- **발생**: "너 남자친구 진짜 괜찮은 사람이네"
- **수량**: 3장

#### ☀️ 좋은 날씨
- **효과**: 다음 데이트 카드 +5점 보너스
- **수량**: 3장

### 부정적 카드 (12장)

#### 🌙 주기 카드
- **효과**: 3턴 동안 변동성 모드 (점수 변화 2배)
- **발생**: "그날"이 찾아옴
- **수량**: 6장
- **중요**: 가장 흔하고 위험한 카드

#### 👥 친구들과의 약속
- **효과**: 다음 턴 데이트 불가
- **발생**: "미안, 내일 친구 만나기로 했어"
- **수량**: 4장

#### 😴 갑작스런 피곤함
- **효과**: 1턴 동안 점수 획득 -5점
- **발생**: "오늘 너무 피곤해..."
- **수량**: 5장

#### 👀 SNS 의심스러운 좋아요
- **효과**: 즉시 -10점
- **발생**: "이 사람은 누구야?"
- **수량**: 3장

### 중립/선택 카드 (8장)

#### 💭 과거 회상 카드
- **효과**: "그때 왜 그랬어?" 질문
- **대응**:
  - 올바른 기억: 0점
  - 잘못된 기억: -25점
  - 기억 못함: -35점
- **수량**: 4장

#### 👨‍👩‍👧 부모님 소개 요구
- **효과**:
  - 준비 안 됨 / 거부: -20점
  - 수락: +30점
- **수량**: 2장

#### 🎂 갑작스런 기념일
- **효과**:
  - 기억하고 있음: +25점
  - 기억 못함: -30점
- **수량**: 2장

## 4. 캐릭터 전용 카드 (각 캐릭터당 3장)

### 완벽주의 센서티브 전용

#### ✨ 완벽한 디테일
- **효과**: 다음 액션 점수 3배
- **조건**: 50점 미만일 때만 사용 가능
- **수량**: 1장

### 비타민 긍정녀 전용

#### 🌺 행복 충전
- **효과**: 외로움 수치 영구 제거 (3턴)
- **조건**: 언제든지
- **수량**: 1장

### 반전 매력의 츤데레 전용

#### 💖 데레 모드
- **효과**: 다음 3턴 동안 모든 효과 즉시 적용
- **조건**: 60점 이상일 때
- **수량**: 1장

### 논리적인 커리어우먼 전용

#### 💼 커리어 응원
- **효과**: 즉시 +20점 (대화 칸 아니어도 가능)
- **조건**: 대화 주제가 일/커리어일 때
- **수량**: 1장

## 카드 드로우 규칙

### 게임 시작 시
- 각 플레이어: 액션 카드 5장
- 특수 카드 1장 (선택)

### 카드 보충
- 매 턴 종료 시: 액션 카드 1장 드로우
- 특정 칸 도착 시: 추가 드로우
- 최대 보유: 7장 (초과 시 버리기)

### 돌발 변수 카드
- 이벤트 칸 도착 시에만 드로우
- 즉시 효과 적용 후 버림

## 카드 콤보 시스템

### 추천 콤보

#### 완벽한 데이트 콤보
1. 취향 저격 선물 (+25점)
2. 영화 데이트 (+10점)
3. 사랑 고백 (+15점)
= **총 50점 획득**

#### 위기 탈출 콤보
1. 기적의 논리 카드 (페널티 절반 회복)
2. 공감 표현 (+10점, 페널티 추가 감소)
3. 타임 프리즈 (다음 턴 보호)
= **안전한 회복**

#### 츤데레 폭발 콤보
1. 깊이 있는 대화 사용 (다음 턴 +12점 예정)
2. 데레 모드 발동 (즉시 적용으로 변경)
3. 같은 턴에 추가 액션 (+12점 즉시)
= **빠른 점수 획득**
