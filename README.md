# 해피 하트 가디언 (Happy Heart Guardian)

> 여자친구의 기분을 세밀하게 관리하며 진정한 사랑을 쟁취하는 보드게임

## 게임 개요

**해피 하트 가디언: 그녀의 마음을 읽는 법**은 상대방의 성향을 파악하고 상황에 맞는 적절한 대응을 하는 것이 핵심인 전략 보드게임입니다.

## 프로젝트 구조

```
happy_guardian/
├── README.md                 # 프로젝트 개요
├── GAME_RULES.md            # 상세 게임 규칙
├── docs/                    # 추가 문서
│   ├── characters.md        # 캐릭터 상세 설명
│   ├── cards.md             # 카드 목록
│   └── strategy-guide.md    # 전략 가이드
└── assets/                  # 게임 리소스
    ├── cards/               # 카드 디자인
    ├── board/               # 보드판 디자인
    └── characters/          # 캐릭터 아트
```

## 게임 특징

- **4가지 독특한 캐릭터**: 각기 다른 난이도와 전략
- **다양한 액션 카드**: 데이트, 선물, 대화 등
- **돌발 상황 시스템**: 예측 불가능한 재미 요소
- **기분 점수 관리**: 0-100점 사이에서 전략적 플레이

## 플레이어 수

2-4명

## 게임 시간

약 30-60분

## 난이도

중급 (캐릭터별로 난이도 차이)
