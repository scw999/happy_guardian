게임 규칙

🎯 목표

15턴 안에 점수 100점을 달성하거나, 가장 높은 점수를 획득하세요!

⚠️ 점수가 0 이하로 떨어지면 게임 오버 (이별)

📋 게임 진행

  1. 주사위 굴리기: 1-6 중 하나의 숫자가 나옵니다
  2. 칸 이동: 나온 숫자만큼 앞으로 이동
  3. 칸 효과: 도착한 칸의 효과를 받습니다
  4. 카드 사용: 적절한 카드를 사용하여 점수를 획득

🎴 칸 종류

  • 💑 데이트 칸: 데이트 카드로 +10점
  • 🎁 선물 칸: 선물 카드로 +8~15점
  • 💬 대화 칸: 대화 카드로 +7~12점
  • 🎭 특수 이벤트: 상황별 선택지 등장 (±50점)
  • ⚡ 이벤트 칸: 랜덤 이벤트 발생
  • ☕ 휴식 칸: 자동으로 +5점

💝 특별 규칙
