# 해피 하트 가디언 웹앱

해피 하트 가디언 보드게임의 웹 버전입니다.

## 🎮 게임 소개

여자친구의 기분을 세밀하게 관리하며 진정한 사랑을 쟁취하는 전략 보드게임의 웹 구현체입니다.

## 📁 파일 구조

```
webapp/
├── index.html              # 메인 HTML 파일
├── css/
│   └── style.css          # 스타일시트
├── js/
│   ├── data.js            # 게임 데이터 (캐릭터, 카드, 이벤트)
│   └── game.js            # 게임 로직
└── images/
    ├── character1-perfectionist.jpg  # 완벽주의 센서티브
    ├── character2-positive.jpg       # 비타민 긍정녀
    ├── character3-tsundere.jpg       # 반전 매력의 츤데레
    └── character4-career.jpg         # 논리적인 커리어우먼
```

## 🚀 시작하기

### 1. 이미지 준비

`images/` 폴더에 4개의 캐릭터 이미지를 저장하세요:
- character1-perfectionist.jpg (빨간 정장 여성)
- character2-positive.jpg (베이지 카디건 여성)
- character3-tsundere.jpg (고딕 스타일 여성)
- character4-career.jpg (검은 정장 여성)

### 2. 웹 서버 실행

#### 방법 1: Python 간이 서버
```bash
cd webapp
python3 -m http.server 8000
```

#### 방법 2: Node.js http-server
```bash
cd webapp
npx http-server -p 8000
```

#### 방법 3: VS Code Live Server
- VS Code에서 `index.html` 열기
- 오른쪽 클릭 → "Open with Live Server"

### 3. 브라우저에서 접속

```
http://localhost:8000
```

## 🎯 게임 방법

### 1. 캐릭터 선택
- 4가지 캐릭터 중 하나 선택
- 각 캐릭터는 다른 난이도와 특성을 가짐

### 2. 게임 진행
1. **주사위 굴리기**: 1-6 랜덤 숫자
2. **칸 이동**: 주사위 결과만큼 이동
3. **칸 효과**: 도착한 칸의 효과 적용
4. **카드 사용**: 적절한 카드 선택
5. **점수 관리**: 0점 미만 = 게임 오버, 100점 = 승리

### 3. 칸 종류
- 💑 **데이트 칸**: 데이트 카드로 점수 획득
- 🎁 **선물 칸**: 선물 카드로 점수 획득
- 💬 **대화 칸**: 대화 카드로 점수 획득
- 🎭 **특수 이벤트**: 상황별 선택지 등장
- ⚡ **이벤트 칸**: 랜덤 이벤트 발생
- ☕ **휴식 칸**: 자동으로 +5점

### 4. 승리 조건
- 15턴 안에 100점 달성
- 또는 15턴 종료 시 가장 높은 점수

## 🎴 카드 시스템

### 데이트 카드
- 영화 데이트: +10점
- 맛집 데이트: +10점
- 산책 데이트: +8점
- 문화 생활: +12점
- 홈 데이트: +9점

### 선물 카드
- 꽃 선물: +8점
- 화장품/향수: +12점
- 책/잡지: +10점
- 패션 아이템: +15점
- 깜짝 선물: +10점

### 대화 카드
- 일상 대화: +7점
- 깊이 있는 대화: +12점
- 사랑 고백: +15점
- 공감 표현: +10점
- 칭찬: +8점

## 🎭 특수 이벤트

게임에는 8가지 특수 이벤트가 포함되어 있습니다:

1. "나 살쪘어?" - 외모 관련 질문 (쉬움)
2. "전 여친이랑 비교하면?" - 위험한 질문 (어려움)
3. "우리 처음 만난 날 기억나?" - 기억력 테스트 (보통)
4. "휴대폰 좀 봐도 돼?" - 신뢰 테스트 (어려움)
5. 감기 걸림 - 간호 기회 (쉬움)
6. 회사에서 힘든 일 - 위로 기회 (보통)
7. 기념일 깜빡 - 최악의 실수 (최고난이도)
8. 친구 vs 데이트 - 우선순위 (보통)

각 이벤트마다 4가지 선택지가 있으며, 선택에 따라 -50점 ~ +50점의 점수 변화가 있습니다.

## 👤 캐릭터 특성

### 💎 완벽주의 센서티브
- 시작 점수: 30점
- 난이도: ⭐⭐⭐⭐⭐
- 특성: 좋은 선택 시 +50%, 나쁜 선택 시 2배 페널티

### ☀️ 비타민 긍정녀
- 시작 점수: 70점
- 난이도: ⭐⭐
- 특성: 높은 시작 점수, 실수에 관대

### 🌸 반전 매력의 츤데레
- 시작 점수: 50점
- 난이도: ⭐⭐⭐
- 특성: 효과가 다음 턴에 반영, 점수 안정적

### 💼 논리적인 커리어우먼
- 시작 점수: 50점
- 난이도: ⭐⭐⭐⭐
- 특성: 대화 카드 +50%, 말실수 -50% 추가 페널티

## 🔧 커스터마이징

### 이벤트 추가
`js/data.js`의 `SPECIAL_EVENTS` 배열에 새 이벤트 추가:

```javascript
{
    id: 'my_event',
    difficulty: 'medium',
    situation: '상황 설명',
    choices: [
        {text: '선택지 1', score: 10},
        {text: '선택지 2', score: -10},
        // ...
    ]
}
```

### 카드 추가
`js/data.js`의 `CARDS` 객체에 새 카드 추가:

```javascript
my_card: {
    id: 'my_card',
    type: 'date', // 'date', 'gift', 'talk', 'special'
    name: '카드 이름',
    icon: '🎯',
    effect: 15
}
```

### 보드판 수정
`js/data.js`의 `BOARD_SPACES` 배열 수정
