# 에셋 디렉토리

이 디렉토리는 해피 하트 가디언 보드게임의 시각적 리소스를 포함합니다.

## 디렉토리 구조

### /cards
카드 디자인 파일들
- 액션 카드 디자인
- 돌발 변수 카드 디자인
- 특수 카드 디자인
- 캐릭터 전용 카드 디자인

### /board
보드판 디자인 파일들
- 메인 보드판 레이아웃
- 점수판 디자인
- 칸별 아이콘

### /characters
캐릭터 아트워크
- 완벽주의 센서티브 일러스트
- 비타민 긍정녀 일러스트
- 반전 매력의 츤데레 일러스트
- 논리적인 커리어우먼 일러스트

## 파일 형식

- 최종 출력: PDF, PNG (고해상도)
- 작업 파일: PSD, AI, SVG

## 제작 가이드라인

### 카드 크기
- 표준 카드 크기: 63mm × 88mm
- 출혈: 3mm
- 안전 영역: 5mm

### 컬러 팔레트
- 완벽주의 센서티브: 퍼플 계열 (#8B5CF6)
- 비타민 긍정녀: 옐로우/오렌지 계열 (#F59E0B)
- 반전 매력의 츤데레: 핑크 계열 (#EC4899)
- 논리적인 커리어우먼: 블루 계열 (#3B82F6)

### 타이포그래피
- 제목: 고딕 계열, Bold
- 본문: 고딕 계열, Regular
- 숫자: Tabular figures 사용

## 추후 추가 예정

현재 디렉토리는 구조만 설정되어 있으며, 실제 디자인 파일은 추후 추가될 예정입니다.
